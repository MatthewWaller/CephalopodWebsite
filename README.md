# Cephalopod Studio Website

A static website showcasing the app portfolio of Cephalopod Studio. The site features iOS, macOS, watchOS, and Vision Pro applications developed by the studio.

## Project Structure

- `index.html` - Homepage with app portfolio
- `blog.html` - Placeholder for future blog content
- `contact.html` - Placeholder for contact information
- `styles.css` - CSS styling for the entire website
- Individual app pages for each application

## Applications Featured

### Apple Multiplatform
- 3D Scanner: Sapling
- Pearl: Meaningful Reminders
- Novel Writing: Candlelight
- ToDon't

### Vision Pro
- Passage
- Very Nice Clocks

## Technologies Used
- HTML5
- CSS3
- SVG

## Deployment
This is a static website that can be deployed to any web hosting service.
